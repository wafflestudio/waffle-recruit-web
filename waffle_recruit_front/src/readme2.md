# 항성계의 공전주기
- 이번 문제는 여러 행성들로 이루어진 항성계의 모습이 주어졌을 때, 해당 항성계의 주기를 측정해야합니다.
- 항성계는 4개의 행성으로 이루어져 있으며 각 행성의 x, y, z 좌표가 주어집니다. 행성들의 **초기 속도는 모두 0**입니다.
- 행성들은 매 스텝마다 주어진 규칙에 따라 움직입니다.
- 항성계의 주기는 행성들이 **처음과 동일한 좌표, 속도** 가 될 때 까지 움직인 스텝의 수입니다.
- 행성들이 1스텝 동안 움직이는 규칙은 아래와 같습니다.
    1. 행성들의 가속도를 체크합니다.
        - 행성 A의 x 축 가속도 = (항성계에서 행성 A보다 x 좌표가 큰 행성의 갯수) - (...행성 A보다 x 좌표가 작은 행성의 갯수)
        - 행성 A의 y 축 가속도 = (항성계에서 행성 A보다 y 좌표가 큰 행성의 갯수) - (...행성 A보다 y 좌표가 작은 행성의 갯수)
        - ...
        - 위 규칙으로 모든 행성들의 x, y, z 가속도를 체크합니다.
    2. 가속도로 행성들의 속도를 업데이트합니다.
        - 각 행성의 각 축 방향 속도 += 각 행성의 각 축 방향 가속도
    3. 속도로 행성들의 좌표를 업데이트합니다.
        - 각 행성의 각 축 방향 좌표 += 각 행성의 각 축 방향 속도

## 예시
- 초기 상태가 다음과 같은 항성계가 있습니다.
```
<x= -1, y=  0, z=  2>
<x=  2, y=-10, z= -7>
<x=  4, y= -8, z=  8>
<x=  3, y=  5, z= -1>
```
- 위 항성계가 첫번째 스텝에서 얻는 가속도는 아래와 같습니다.
    - 위에서 부터 순서대로 행성 이름을 A,B,C,D 로 붙입니다.
    - A의 x 축 방향 가속도는 `-1 < 2,  -1 < 4, -1 < 3`으로 세 행성이 자기보다 x 축 방향 좌표가 크기 때문에 3 - 0 = 3 입니다.
    - A의 y 축 방향 가속도는 `0 > -10, 0 > -8, 0 < 5`으로 한 행성이 자기보다 y 축 방향 좌표가 크고, 두 행성이 자기보다 y 축 방향 좌표가 작기 때문에 1 - 2 = -1 입니다.
    - 위 방법을 A의 z 축과 다른 모든 행성에 적용해 가속도를 구합니다.
